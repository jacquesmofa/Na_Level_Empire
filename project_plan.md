# Na Level Empire Media — Website

## 1. Project Description
Na Level Empire Media (NLEM) is a Toronto-based audiovisual production and event management social enterprise. The website serves as a high-authority hub for media production services, career development, and corporate strategy. Target users: nonprofits, government agencies, educational institutions, and mission-driven businesses across the GTA.

## 2. Page Structure
- `/` - Home (hero, services, stats, latest work)
- `/projects` - Projects & Portfolio
- `/media` - Media Hub (YouTube content)
- `/news` - News & Stories
- `/impact` - Social Impact
- `/careers` - Careers & Training
- `/about` - About NLEM
- `/contact` - Contact / Get a Quote
